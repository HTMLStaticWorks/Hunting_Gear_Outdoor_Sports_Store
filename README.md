# Vanguard Outpost & Expedition Co. — Hunting Gear & Outdoor Sports Store

A multi-page, modern website for **Vanguard Outpost & Expedition Co.**, an elite hunting gear and outdoor sports outfitter based in Bozeman, Montana.

## 🌲 Highlights & Feature Matrix

- **Multi-Page Catalog & Showcase Architecture:**
  - `pages/index.html` (Home 1 — Seasonal Armory Focus — Exactly 6 Sections)
  - `pages/home-2.html` (Home 2 — High-Alpine Expedition & Survival Focus — Exactly 6 Sections)
  - `pages/products.html` (Master Catalog: Apparel, Optics, Accessories — Exactly 4 Sections)
  - `pages/safety-regulations.html` (Hunter Safety, Blaze Orange, Laws — Exactly 4 Sections)
  - `pages/trade-in.html` (4-Step Workflow & Appraisal Calculator — Exactly 4 Sections)
  - `pages/contact.html` (Validated Enquiry Form, Google Maps, Facility Guide — Exactly 4 Sections)
  - `pages/404.html` (Custom Lost Coordinates Page with Spinning 3D Compass)
  - `pages/coming-soon.html` (Next-Gen Thermal Vault with Live Countdown Timer)

- **Strict Aesthetic & Interaction Rules:**
  - **3D Tilt Cards:** Physics-based tilt with specular glare, center-aligned icons & text on ALL views.
  - **Ambient 3D Topographic Canvas:** Procedural contour elevation waves with mouse depth displacement.
  - **No Generic Styles:** Curated outdoor palette (deep pine green, charcoal gunmetal, burnt blaze orange, khaki tan).
  - **Dark & Light Mode:** System-detected and manually toggleable.
  - **Bidirectional RTL Support:** Full right-to-left layout compatibility via `assets/css/rtl.css`.
  - **Clean Navigation:** Strictly 5 items in navbar, no login, no dashboard buttons.
  - **Local High-Resolution Assets:** All images stored locally in `assets/images/`.

## 🚀 How to Run Locally

You can run this site using Python's built-in HTTP server:

```bash
# In the project root:
python -m http.server 8000
```

Then open your browser to `http://localhost:8000`.
